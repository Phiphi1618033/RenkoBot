# RenkoBot

# Renko Telegram Bot

Receives TradingView webhook alerts and forwards them to Telegram.

## Environment Variables

TELEGRAM_BOT_TOKEN

TELEGRAM_CHAT_ID

WEBHOOK_SECRET

## Deploy

1. Push to GitHub
2. Import project into Vercel
3. Add environment variables
4. Deploy

Webhook URL:

https://YOUR-PROJECT.vercel.app/api/webhook
